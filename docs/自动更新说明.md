# 自动更新说明（GitHub Releases + Pages）

配套 App：v1.0.9 及以上  
费用：0 元（使用 GitHub 免费额度）

---

## 1. 原理

```text
App 启动
  → 请求 https://用户名.github.io/仓库名/update.json
  → 比较 versionCode
  → 有新版本：弹窗
  → 用户点“立即更新”
  → 下载 GitHub Release 里的 APK
  → 校验 SHA-256
  → 拉起系统安装界面
  → 用户点“安装”覆盖旧版
```

普通 App 无法静默安装，最后一步必须由用户确认。

---

## 2. 一次性配置

### 2.1 创建 GitHub 仓库

把本项目推送到 GitHub，例如：

```text
https://github.com/l2197096277-pixel/RGB_APP
```

### 2.2 开启 Pages

仓库 **Settings → Pages**：

- Source：`Deploy from a branch`
- Branch：`gh-pages`
- Folder：`/ (root)`

第一次发布后 `gh-pages` 分支才会出现。

### 2.3 配置 Secrets

仓库 **Settings → Secrets and variables → Actions**，新增：

| Secret | 内容 |
|---|---|
| `KEYSTORE_BASE64` | `keystore/aurora-release.jks` 的 Base64 |
| `KEYSTORE_PASSWORD` | keystore 密码 |
| `KEY_ALIAS` | `aurora` |
| `KEY_PASSWORD` | key 密码 |

生成 Base64（PowerShell）：

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("keystore/aurora-release.jks")) | Set-Clipboard
```

> 不要把 keystore、密码、Base64 提交到公开仓库。

### 2.4 修改 App 更新地址

已配置为你的仓库：

```properties
AURORA_UPDATE_URL=https://l2197096277-pixel.github.io/RGB_APP/update.json
```

如果仓库改名，同步修改这里。

### 2.5 GitHub Actions 权限

仓库 **Settings → Actions → General → Workflow permissions**：

- 选择 **Read and write permissions**；
- 允许 GitHub Actions 创建 Release 和推送 `gh-pages`。

---

## 3. 发布新版本

1. 修改代码；
2. 提升 `app/build.gradle` 里的 `versionCode` 和 `versionName`；
3. 更新 `CHANGELOG.md`；
4. 提交并打 tag：

```bash
git tag v1.0.10
git push origin v1.0.10
```

或者 GitHub Actions 页面手动运行 `Release AuroraLight`。

Workflow 会自动：

- 构建签名 APK；
- 创建 GitHub Release；
- 上传 APK；
- 生成 `update.json`；
- 推送到 `gh-pages`。

App 下次启动就会看到更新弹窗。

---

## 4. update.json 格式

```json
{
  "versionCode": 11,
  "versionName": "1.0.10",
  "apkUrl": "https://github.com/l2197096277-pixel/RGB_APP/releases/download/v1.0.10/AuroraLight-v1.0.10.apk",
  "sha256": "APK的SHA256",
  "changelog": "1. 修复...\n2. 新增...",
  "force": false
}
```

- `force=true`：不可取消，只能更新或退出；
- `force=false`：可以点“稍后”。

---

## 5. 手机端要求

- Android 8 及以上首次更新需要允许“安装未知应用”；
- App 会引导打开系统设置；
- 返回 App 后会自动继续安装；
- 必须使用同一个签名证书，否则系统拒绝覆盖安装。

---

## 6. 费用

- GitHub 仓库/Releases/Pages/Actions：免费额度内 0 元；
- 国内访问 GitHub 可能较慢；
- 如果以后用户量大、下载慢，可以只把 `update.json` 和 APK 换到阿里云 OSS，App 代码不用改，只改 URL。
