# v1.1.3 更新日志（详细）

发布日期：2026-11-15  
versionCode：14  
versionName：1.1.3

## 一、固件版本与强制升级修正

- `fota.json` 新增 `force` 字段；
- `versionCode` 重新作为真实固件版本，用于比较和本地记录；
- `force: true` 时向设备发送 `0xFFFF` 强制升级；
- 升级成功后记录真实 `versionCode`，不再记录 `65535`；
- 迁移旧版本误存的 `last_fw_version=65535`；
- `fota.json` 请求增加 no-cache，避免读到旧版本号。

示例：

```json
{
  "versionCode": 4097,
  "versionName": "1.0.1",
  "force": false,
  "fileUrl": "...",
  "sha256": "..."
}
```

需要强制重刷时：

```json
"force": true
```

## 二、正常界面更新日志

- 正常“我的”页只显示当前版本日志；
- 当前日志只保留日期，不显示具体时间；
- 历史版本列表默认隐藏；
- 历史版本只在开发者模式显示；
- 开发者模式下点“查看历史”才展开。

## 三、OTA 日志

- 开发者模式下，OTA 页面右上角显示 `Log` 按钮；
- 可查看：
  - OTA 状态；
  - 当前版本；
  - 目标版本；
  - `force` 状态；
  - TX/RX 原始字节；
  - 下载与 SHA-256；
  - 失败原因；
- 正常用户不显示 Log 按钮。

## 四、连接恢复

- OTA 失败后返回 App；
- 普通控制重新连接；
- 若自动连接失败，可点“连接灯光”。
