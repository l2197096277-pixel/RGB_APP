# v1.2.0 更新日志

发布日期：2026-11-15  
versionCode：21  
versionName：1.2.0

## 一、新协议 V1.0.1

- 跑马灯增加颜色字节：

```text
11 00 02 02 x y 0A
```

- 呼吸灯增加颜色字节：

```text
11 00 03 02 x y 0A
```

- 新增实际 RGB 灯珠数量设置：

```text
11 00 06 01 x 0A
```

- `x` 为 1–255；
- 开灯前必须设置；
- 开灯后不能修改，必须先关灯；
- 普通指令仍连续发送 3 次，间隔 100ms；
- 颜色顺序仍为：

```text
01 白、02 红、03 橙、04 黄、05 绿
06 青、07 蓝、08 紫、09 品红
```

## 二、灯珠数量

- 控制页新增“实际灯珠数量”卡片；
- 输入框默认不预填；
- 必须输入 1–255 并点“应用”；
- 应用后发送 06 指令 3 次；
- 未应用时点总开关会被拦截并提示；
- 开灯后输入框和应用按钮禁用；
- 关灯后才能重新输入、重新应用；
- 每次开灯前都要重新应用；
- 常亮“亮灯数量”作为本次亮灯颗数，不能超过实际灯珠数量。

## 三、跑马灯/呼吸灯颜色

- 跑马灯、呼吸灯、焰火、常亮都显示颜色选择；
- 运行中切换颜色会立即重发当前模式帧；
- 模式帧使用新协议 2 字节格式。

## 四、我的设备重复修复

- 同一产品名称只保留一条历史记录；
- 蓝牙地址变化时更新该记录的地址，不再新增；
- 老版本留下的同名重复记录会自动合并；
- 自动连接、历史直连都使用最新地址。

## 五、历史设备直连失败

- 先按历史地址直连；
- 直连失败自动重新扫描；
- 扫描到同一产品名称或 RGB 产品标识后自动重连；
- 仍找不到时提示手动扫描；
- 连接成功后只有点击“我的设备”里的设备才进入控制页。
