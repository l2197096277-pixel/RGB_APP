# v1.1.4 更新日志（详细）

发布日期：2026-11-15  
versionCode：15  
versionName：1.1.4

## 一、广播识别 RGB 产品

- 扫描时识别广播中的 `FF01` / RGB 产品标记；
- 兼容 Service UUID、Service Data、Manufacturer Data 中的 `FF01` / `01 FF`；
- 识别到后列表显示：

```text
我的产品 · RGB灯
已识别为 RGB 灯
```

- 自动排在普通设备前面；
- 避免同名蓝牙设备连接错误。

## 二、消除“写入失败，请重试”误提示

- 原因：连接后订阅 FF02 的 CCCD 写操作尚未结束，紧接发送同步指令时 GATT 忙，`writeCharacteristic` 返回 false；
- 普通控制现在只使用 FF01 写，不抢占 GATT 做 FF02 订阅；
- 写忙时自动重试 2 次，不再立即弹“写入失败”；
- 只在连续失败后才提示。

## 三、开发者模式长按改为 10 秒

- 长按版本号时间从系统默认约 0.5 秒改为 **10 秒**；
- 触发后有震动反馈；
- 正常短按/轻触不会进入开发者模式。

## 四、保留

- 正常界面只显示当前版本日志；
- 历史日志只在开发者模式；
- OTA 页面开发者模式显示 Log；
- `force` 与真实 `versionCode` 分离；
- `fota.json` 禁用缓存。

## 五、版本规则

```text
1.1.0 → 1.1.1 → 1.1.2 → 1.1.3 → 1.1.4 → 1.2.0
```
