# v1.1.2 更新日志（详细）

发布日期：2026-11-14  
versionCode：13  
versionName：1.1.2

## 一、灯带固件 OTA 入口

- “我的”页新增“灯带固件”模块；
- 显示当前固件版本；
- “检查更新”一行可点击；
- 有可用固件时显示红点；
- 点开后先读取设备固件版本，再对比 `fota.json`。

## 二、固件升级流程

1. 连接灯带；
2. 点“检查更新”；
3. App 读取当前固件；
4. 对比最新固件；
5. 有更新时弹窗：“发现新固件”，按钮“是 / 否”；
6. 选“否”不升级，红点保留；
7. 选“是”弹窗提示升级注意事项，按钮“了解 / 退出”；
8. 点“了解”后下载 `.fot`；
9. SHA-256 校验；
10. 通过 FF12 / FF14 / FF15 升级；
11. 进度条 + 百分比；
12. 成功后提示“升级成功，请返回 App 重新连接”；
13. 失败后显示具体错误和处理建议。

## 三、升级期间

- 进入独立 OTA 页面，屏蔽灯光控制；
- 不能返回、不能点外部关闭；
- 保持屏幕常亮；
- 不允许同时升级 App；
- 显示当前固件、目标固件、进度、状态。

## 四、正常控制迁移到 FF12

- 正常灯光控制从 BBB0/BBB1 迁移到 FF12/FF01；
- FF02 订阅状态通知；
- FF03 作为兼容/预留写特征值；
- OTA 继续使用 FF14/FF15。

## 五、使用官方 FOTA 库

- 移植官方 `AB-OTA-Demo` 的 `fota` 模块；
- FF12 服务；
- FF14 Notify；
- FF15 Write No Response；
- 握手、版本查询、0x91/0x92、0xA0/0x20、0x90 状态；
- 支持普通 `.fot` 和压缩 `.fot`（POT）。
