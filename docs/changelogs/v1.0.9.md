# v1.0.9 更新日志（详细）

发布日期：2026-11-13  
versionCode：10  
versionName：1.0.9

## 一、GitHub 自动更新

- App 启动后请求 `update.json`，检查 `versionCode`；
- 有新版本时弹窗显示版本号和更新内容；
- 点击“立即更新”后下载 APK；
- 下载完成校验 SHA-256；
- 自动拉起 Android 系统安装界面；
- 可选更新/强制更新由 `update.json` 的 `force` 控制；
- 普通 App 无法静默安装，最后需要用户点一次系统“安装”。

## 二、GitHub Releases + Pages 发布

- 新增 `.github/workflows/release.yml`；
- 打 `v*` tag 或手动运行 workflow 即可：
  1. 构建签名 APK；
  2. 上传到 GitHub Release；
  3. 生成 `update.json`；
  4. 发布到 `gh-pages`；
- App 只需要一个静态 HTTPS 地址：
  `https://用户名.github.io/仓库名/update.json`

## 三、自动连接上次设备

- 首次通过扫描连接后，保存设备 MAC 和名称；
- 后续启动 App，如果权限和蓝牙已开启，直接用保存的地址连接；
- 不需要每次都重新扫描；
- 自动连接失败时，仍可点“连接灯光”手动扫描；
- 连接成功后仍然默认关灯，需要用户自己按总开关。

## 四、权限变化

- 新增 `INTERNET`：仅用于检查更新和下载 APK；
- 新增 `REQUEST_INSTALL_PACKAGES`：用于拉起系统安装器；
- 新增 `FileProvider`；
- 隐私说明改为“仅联网检查更新，不上传个人信息”。

## 五、保留

- 自检、亮灯数量、自定义单灯、彩色灯珠、内置调色；
- 普通指令 3 次 / 100ms；
- 自定义 `11 12 02 x y` 串行队列；
- 连接后默认关灯；
- 开发者日志仅“我的”页显示；
- 启动动画 1.25 秒。

## 六、配置

- `gradle.properties` 的 `AURORA_UPDATE_URL` 需要改成你的 GitHub Pages 地址；
- GitHub Actions 需要配置 `KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD` 四个 Secrets；
- 仓库 Settings → Pages → Source 选择 `gh-pages` 分支。
