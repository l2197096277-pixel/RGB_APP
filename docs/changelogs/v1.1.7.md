# v1.1.7 更新日志（详细）

发布日期：2026-11-15  
versionCode：18  
versionName：1.1.7

## 一、删除音乐二次确认

- 点“删除”先弹窗：
  - 标题：删除音乐？
  - 内容：确定从列表删除“歌曲名”吗？
  - 按钮：取消 / 删除
- 只有点“删除”才真正移除；
- 删除当前播放歌曲时停止播放并释放音频分析；
- 删除非当前歌曲时修正播放索引。

## 二、自检二次确认

- 点“自检”先弹窗：
  - 标题：开始自检？
  - 内容：确认后灯带会执行自检效果。
  - 按钮：取消 / 开始自检
- 已处于自检状态时，再点一次只执行关闭，不再重复确认。

## 三、焰火模式

- 原“火焰灯”名称改为“焰火”；
- 焰火预览改为向上运动的不规则火苗/火星；
- 不再使用横向波浪/山形移动；
- 颜色跟随当前选择的颜色；
- 动画持续、平滑循环。

## 四、返回箭头

- 控制页和音乐页左上角改用矢量返回箭头；
- 修正字符箭头倾斜、不居中问题。

## 五、App 图标

- 使用用户提供的叶子/光环图标；
- 生成 mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi 五套；
- 同时生成圆形图标；
- 包名、签名、OTA、自动更新均不变。
