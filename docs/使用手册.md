# 幻彩灯控 · 使用手册

版本：v1.0.9  
适用系统：Android 6.0 及以上（需支持低功耗蓝牙 BLE 4.0+）  
App 名称：幻彩灯控（Aurora Light）

---

## 1. 这是什么

一个**不需要注册、不需要登录**的蓝牙幻彩灯控制 App；仅联网检查 GitHub 更新和下载新版本。打开后自动连接上次设备，也可以扫描新设备，控制开关、亮度、颜色、光效和速度。

App 只做三件事：

1. 通过低功耗蓝牙（BLE）发现附近的幻彩灯；
2. 向灯带发送控制指令；
3. 接收灯带回报的状态，保持界面同步。

所有设置保存在手机本地，不会上传到任何服务器。

---

## 2. 30 秒上手

1. 给灯带通电，确认灯带处于可被蓝牙发现的状态。
2. 安装 `AuroraLight-v1.0.9.apk`（首次安装需允许“安装未知来源应用”）。
3. 打开 App。首次使用会弹出系统权限请求，请允许“附近的设备”；Android 11 及以下请允许定位权限并打开系统定位开关。
4. 点底部的 **“连接灯光”**，或点右上角状态胶囊。
5. 在底部面板中选择名称以 `AuroraLight-` 开头的设备。
6. 连接成功后，App 会自动把当前开关、亮度、颜色、光效同步给灯带。

> 没有灯带也可以先点 **“没有设备？点此体验演示模式”**，完整预览界面和操作。演示模式不会发送真实蓝牙指令。

## 3. 界面说明

### 3.1 顶部状态

| 显示 | 含义 |
|---|---|
| 灰色 · 未连接 | 尚未连接灯带，可以预先调好设置，连接后自动同步 |
| 紫色 · 连接中 | 正在建立蓝牙连接 |
| 绿色 · 已连接 | 已连接并可以发送指令 |
| 琥珀色 · 演示模式 | 当前操作只在本机模拟 |

点状态胶囊：未连接时打开扫描面板；已连接时显示当前设备名。

### 3.2 主开关

中央的大圆形按钮是总开关。

- 轻触：开灯 / 关灯。
- 开启时外圈有呼吸光晕，按钮颜色会跟随当前灯光颜色变化。
- **未连接蓝牙时不能切换**，会提示“请先连接蓝牙，再开关灯光”。

### 3.3 亮度

拖动滑块，顶部右侧显示 0–100% 的数值。**拖动过程中每约 120ms 发送一次当前亮度**，松手后再补发 3 次，避免只在松手时发码。

### 3.4 光效模式

| 模式 | 说明 |
|---|---|
| 流光跑马 | 颜色沿灯带流动（协议跑马灯） |
| 呼吸 | 亮度缓慢起伏 |
| 律动 | 跟随节拍闪烁（协议律动） |
| 火焰 | 暖色随机闪烁（协议火焰） |

点卡片即可切换。被选中的卡片有薄荷色描边和图标高亮。

### 3.5 律动速度

“慢 / 标准 / 快”三个档位，对应协议中的速度值 30 / 60 / 90。只对动态光效明显。

### 3.6 灯光颜色

九个协议颜色，对应协议颜色码 1–9：

- 红、橙、黄、绿、青、蓝、紫、白、品红

点颜色会自动切换到静态色，App 发送 `11 08 01 0n CS`（`n=1–9`）。

再次点击当前已高亮的颜色，会关闭颜色并发送：

```text
11 08 01 00 1A
```

### 3.7 亮灯数量

“光效”页的亮灯数量：

- 默认 **1 个**；
- `−` / `+`：每次 1 颗，直接发送 `11 07`；
- 数值显示“当前 / 255”；
- 颜色只作用于当前亮灯数量；
- `0x07` 是相对命令，App 每次只发 1 次，避免重复 3 次后多加 3 颗。

### 3.8 自检

“光效”页的“自检 · 让灯珠跑一遍”：

- 点击发送 `11 FF 01 01 12`，按钮高亮；
- 再点发送 `11 FF 01 00 11`，取消高亮；
- 关灯、一键关闭、重新连接会自动取消自检。

### 3.9 自定义灯光

“光效”页的“自定义灯光 · 逐颗设置要亮的灯”进入全屏界面：

1. 先输入产品实际灯珠总数（1–255）；
2. 点“生成”，生成 1…N 的灯珠按钮；
3. 点灯珠点亮，再点一次关闭；可以同时点亮多颗；
4. 自定义界面顶部也有 9 色圆点，选色会作用于已经点亮的灯；
5. 快速点击会排队发送，上一组 3 次发完才发下一组，不会跳过；
6. 退出时发送 `11 12 02 00 00 25`。

单颗灯格式：

```text
11 12 02 x y CS
```

例如点亮第 3 颗：`11 12 02 03 01 29`；关闭第 3 颗：`11 12 02 03 00 28`。

输入的总数在退出/再次进入时保留，直到重新连接蓝牙才清空；点“清除”可以手动重新输入。

### 3.10 开发者模式

进入“我的”页面，**长按版本号**：

- 长按进入开发者模式，再长按退出；
- 整个 App 仍然只有一个 Activity，不跳转新页面；
- 开发者模式下方会显示 App **实际发出的十六进制码**，字号较小，可滚动，右上角“清空”；
- App 界面不提供“长按进入”的文字提示。

每条控制命令会连续发送 **3 次，间隔 100ms**，所以日志里会看到同一条码重复 3 行。

### 3.11 一键关闭

第一页“一键关闭”按钮发送协议命令 `11 11 01 00 23`，同时：

- 总开关关闭；
- 所有模式高光熄灭；
- 亮度显示 0%；
- 颜色选中环熄灭。

### 3.12 连接 / 断开

底部主按钮会根据状态变化：

- **连接灯光**：打开扫描面板。
- **正在连接…**：轻触可取消连接。
- **已连接 · 轻触断开**：断开当前灯带。
- **演示模式 · 轻触退出**：退出演示。

### 3.13 自动连接

- 第一次通过扫描连接成功后，App 会保存设备地址；
- 后续启动 App，如果蓝牙和权限已开启，会直接用保存的地址连接；
- 不需要每次重新扫描；
- 自动连接失败时，仍可点“连接灯光”手动扫描；
- 自动连接成功后默认关灯，需要你自己按总开关。

### 3.14 自动更新

- App 启动后会检查 GitHub 上的 `update.json`；
- 有新版本会弹窗显示更新内容；
- 点“立即更新”下载 APK，校验 SHA-256 后拉起系统安装；
- 普通 App 无法静默安装，最后需要点一次系统“安装”；
- 详细配置见 `docs/自动更新说明.md`。

## 4. 连接与权限

### 4.1 Android 12 及以上

需要“附近的设备”权限（`BLUETOOTH_SCAN` + `BLUETOOTH_CONNECT`）。App 声明了 `neverForLocation`，不需要定位权限，也不会读取位置。

### 4.2 Android 6–11

系统限制：扫描 BLE 必须拥有定位权限，并且系统定位开关处于开启状态。App 不读取、不保存位置；定位权限只用于系统允许扫描蓝牙。

### 4.3 权限被拒绝

在扫描面板中：

- 点 **“重新授权”** 再次请求；
- 或点 **“权限被拒绝？打开系统设置”**，在系统设置里手动开启；
- 也可以先进入演示模式。

### 4.4 蓝牙未开启

面板会显示“蓝牙未开启”。点 **“开启蓝牙”** 后按系统提示操作，返回 App 会自动重新检测。

## 5. 设备兼容性（重要）

这个 App 使用**自定义 BLE 指令协议**，并使用中科蓝讯的 16 位 UUID：

- 服务 UUID：`0000BBB0-0000-1000-8000-00805F9B34FB`（`0xBBB0`）
- 控制特征值：`0000BBB1-0000-1000-8000-00805F9B34FB`（`0xBBB1`）
- 状态特征值：`0000BBB2-0000-1000-8000-00805F9B34FB`（`0xBBB2`）
- 只读信息：`0000BBB3-0000-1000-8000-00805F9B34FB`（`0xBBB3`，可选）
- 广播名称：`AuroraLight-XXXX`

App **只向 `0xBBB1` 写指令**，不读取 `0xBBB2/BBB3`，也不订阅 Notify；因此固件只要实现 `0xBBB1` 的写回调即可。

因此：

- **可以连接**：已经按本协议实现固件的灯带（参考项目内 ESP32 固件）。
- **不能直接连接**：市面上使用厂商私有协议、UUID 和指令都不同的成品灯带。App 会提示“该设备不是幻彩灯：未找到自定义服务”。
- 如果你的灯带是可编程控制器（ESP32 / nRF52 / Arduino + BLE 模块），可以烧录项目内的参考固件，或按《BLE 协议规范》适配现有固件。

> 换句话说：手机是“主机”，灯带是“从机”。只有灯带按约定广播并提供对应服务，App 才能控制它。

## 6. 常见问题

### Q1：扫描不到灯带？

按顺序检查：

1. 灯带是否通电，是否处于可连接状态；
2. 手机蓝牙是否开启；
3. Android 12+ 是否允许“附近的设备”；Android 11 及以下是否允许定位且打开定位开关；
4. 灯带是否在 5 米内，中间是否有强干扰源；
5. 灯带固件是否真的广播了 `0000BBB0-0000-1000-8000-00805F9B34FB`；
6. 是否已被其他手机连接（BLE 从机通常只允许一个中心设备连接）；
7. 点“重新扫描”再试。

### Q2：能连上，但提示“设备固件不完整”？

设备提供了自定义服务，但缺少控制或状态特征值。请核对固件里的三个 UUID 是否与协议完全一致，尤其是 `0002` / `0003` 这两段。

### Q3：连接后点按钮没反应？

- 看顶部状态是否为绿色“已连接”；
- 看灯带固件是否实现了对应指令；
- 在开发者文档的“测试清单”中用 nRF Connect 手动写一帧，确认固件能响应；
- 若使用 iOS 或电脑调试，请确认写入方式为 **Write With Response**。

### Q4：为什么 App 没有“登录 / 注册”？

这是刻意设计。没有账号体系，没有云端，没有广告 SDK。安装即用，所有偏好只写入本机 `SharedPreferences`。

### Q5：换手机后设置还在吗？

不在。设置保存在本机，不联网同步；仅更新检查会访问 GitHub。重新连接后 App 会把当前界面状态同步给灯带。

### Q6：卸载重装后签名冲突？

请先卸载旧版本再安装。不同签名的 APK 不能直接覆盖安装。

### Q7：灯带颜色和 App 里选的不完全一样？

RGB 灯珠存在批次差异，且固件可能做了亮度/色温校正。可在固件里对 RGB 做校准，或选择更接近的颜色。

## 7. 隐私与安全

- **INTERNET 权限仅用于检查 GitHub 更新和下载 APK**，不上传个人信息。
- 没有账号、手机号、邮箱、通讯录、相册、位置读取逻辑。
- 不收集、不上传任何蓝牙数据或个人数据。
- 蓝牙连接不配对、不加密，适合个人近距离灯光控制；不要用于门锁等安全场景。
- 设置仅存储在本机，卸载 App 即删除。

---

## 8. 卸载与更新

- 更新：使用同一签名的新 APK 覆盖安装，设置会保留。
- 卸载：长按桌面图标 → 应用信息 → 卸载；或在系统设置中卸载。
- 签名密钥保存在项目 `keystore/aurora-release.jks`。**后续升级必须使用同一密钥**，否则只能卸载重装。
