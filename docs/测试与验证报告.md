## 4. 本轮功能验证

### 4.1 颜色再次点击关闭

- 当前颜色高亮时再次点击：取消高亮，发 `11 08 01 00 1A`；
- 选其它颜色仍正常；
- 关灯/开光效时颜色高亮熄灭。

### 4.2 亮灯数量

- 默认 1 个；
- `−`/`+` 每次 1 颗，直接发送 `11 07`（相对命令只发 1 次）；
- 颜色作用于当前数量；同步帧带数量。

### 4.3 自定义灯光

- 输入 1–255 颗后生成 1…N 按钮；
- 点击点亮/关闭，单灯帧 `11 12 02 x y`；
- 快速点击进入串行队列，每组 3 次 / 100ms，不跳过；
- 退出发 `11 12 02 00 00 25`，排在待发指令之后；
- 数量保留到重新连接，支持手动清除。

### 4.4 自检

- 按钮发送 `11 FF 01 01 12`，再按发 `11 FF 01 00 11`；
- 高亮同步，关灯/重连自动取消。

### 4.5 发送节奏

- 普通指令改为 3 次 / 100ms；
- 亮度拖动约 120ms 一次，松手 3 次；
- 0x07 相对数量例外，只发 1 次。

### 4.6 只发不读

- 移除 Status/Notify/CCCD；
- 只要求 BBB1 控制特征值；
- 连接成功直接 markReady；
- 不读取、不订阅设备数据。

### 4.4 启动动画

- `IntroOverlayView` 约 0.9 秒；
- RGB 柔光 + 灯带 + AURORA 字样；
- 淡出移除，不阻塞主界面。

### 4.5 未连接拦截

- 总开关、模式、颜色、速度、数量、一键关闭均检查连接；
- 提示“请先连接蓝牙，再……”；
- 总开关未开时提示“请先打开总开关再……”；
- 演示模式作为明确例外。

### 4.6 已有功能

- 三页界面、左右滑动、底部导航；
- 模式短按开启/再按关闭；
- 颜色需光效关闭；
- 亮度拖动实时发码 + 松手 3 次；
- 一键关闭；
- 扫描 8 秒、积极扫描参数；
- 版本号长按开发者模式，界面无提示。

---

### 4.7 自动连接

- 首次连接成功后保存 `last_device_address`；
- 下次启动若权限/蓝牙已开启，直接 `connectAddress`，不重新扫描；
- 失败时保留手动扫描入口；
- 连接成功仍默认关灯。

### 4.8 GitHub 自动更新

- `INTERNET` + `REQUEST_INSTALL_PACKAGES` + FileProvider 已加入；
- 启动请求 `update.json`，比较 versionCode；
- 弹窗、下载、SHA-256 校验、系统安装；
- `force` 控制强制/可选；
- GitHub Actions 发布 workflow 已加入；
- 未配置 URL 时跳过检查，不影响 App。

## 7. 已知风险

1. 校验和是补充定义；原厂若不是累加和，需同步修改。
2. 协议未定义设备→手机状态帧，App 也不读取。
3. `0x07` 是相对命令，不能盲目重复 3 次；App 只发 1 次。
4. 开发者模式日志保留最近 120 行。
