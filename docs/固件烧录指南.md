# ESP32 参考固件烧录指南

本指南用于把项目内的 `firmware/aurora_light_esp32/aurora_light_esp32.ino` 烧录到 ESP32，让灯带按 App 的自定义 BLE 协议工作。

> 已有成品灯带（厂商私有协议）不能直接套用本固件，除非你能拆开更换控制器或修改原固件。请先阅读《使用手册》第 5 节“设备兼容性”。

---

## 1. 你需要准备

### 硬件

- ESP32 开发板（ESP32-WROOM-32 / ESP32-DevKitC 等，带 BLE）
- WS2812B / SK6812 灯带（示例 60 颗）
- 5V 电源（电流 ≥ 灯珠数 × 60mA × 0.6，建议留余量）
- 电平转换/驱动（3.3V 数据 → 5V 灯带，可用 74HCT245 或 330Ω 串联电阻）
- 杜邦线、USB 数据线

### 接线

| ESP32 | 灯带 |
|---|---|
| GPIO 5（可改 `LED_PIN`） | DIN |
| GND | GND |
| 5V（独立电源） | 5V |
| GND（独立电源） | GND（必须与 ESP32 共地） |

**大功率灯带不要从 ESP32 的 5V 引脚取电**，否则容易烧板或掉压重启。长灯带请每隔 2–3 米补电。

### 软件

- Arduino IDE 2.x
- ESP32 开发板支持包（Arduino-ESP32 **2.0.x**，例如 2.0.17）
- 库：
  - **FastLED 3.6.x**
  - **NimBLE-Arduino 1.4.3**（注意不要装 2.x，回调签名不同）

---

## 2. 安装 ESP32 开发板

1. 打开 Arduino IDE → File → Preferences。
2. 在 “Additional boards manager URLs” 填入：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. Tools → Board → Boards Manager，搜索 `esp32`，安装 **2.0.17**（或 2.0.x 系列）。
4. Tools → Board 选择 **ESP32 Dev Module**。
5. 端口选择 ESP32 对应的 COM 口。

---

## 3. 安装库

### 方式 A：库管理器

1. Sketch → Include Library → Manage Libraries。
2. 搜索 `FastLED`，安装 3.6.x。
3. 搜索 `NimBLE`，选择 **NimBLE-Arduino 1.4.3** 安装。
   - 如果只能看到 2.x，请到 GitHub Releases 下载 1.4.3 的 ZIP，再用 Sketch → Include Library → Add .ZIP Library 安装。

### 方式 B：手动

把库解压到 `Documents/Arduino/libraries/`，确认目录结构：

```
libraries/
├─ FastLED/
└─ NimBLE-Arduino/
```

---

## 4. 修改参数

打开 `aurora_light_esp32.ino`，按你的硬件修改：

```cpp
#define LED_PIN       5      // 数据线接的 GPIO
#define NUM_LEDS      60     // 灯珠数量
#define LED_TYPE      WS2812B
#define COLOR_ORDER   GRB    // 常见 WS2812B 是 GRB；颜色不对时改 RGB
#define MAX_MILLIAMPS 2500   // 电源限流，按实际电源调整
```

- 灯带颜色红绿颠倒：把 `COLOR_ORDER` 改为 `RGB` 或 `BGR`。
- 灯带闪烁/重启：降低 `MAX_MILLIAMPS`，检查共地，给 ESP32 单独稳压。
- 只有前几颗亮：`NUM_LEDS` 设大了或电源压降，检查补电。

## 5. 编译与烧录

1. 用 Arduino IDE 打开 `.ino`。
2. 点左上角“验证”（✓）编译。
3. 连接 ESP32，点“上传”（→）。
4. 打开 Serial Monitor，波特率 **115200**，复位板子，应看到：
   ```
   AuroraLight ready: AuroraLight-3F7A
   ```
   名称后缀来自 ESP32 的蓝牙 MAC 后两字节。

### 常见编译错误

| 错误 | 原因 | 解决 |
|---|---|---|
| `NimBLECharacteristicCallbacks::onWrite` 参数不匹配 | 装了 NimBLE 2.x | 换回 1.4.3 |
| `esp_read_mac` 未声明 | 缺少头文件 | 确认 `.ino` 中有 `#include <esp_mac.h>` |
| `FastLED` 找不到 | 库未安装 | 库管理器安装 FastLED |
| 上传超时 | 没按 BOOT / 串口被占用 | 按住 BOOT 再点上传，关闭其他串口工具 |
| 灯不亮但串口正常 | 接线/颜色顺序/电源 | 检查 DIN、GND、5V、`COLOR_ORDER` |

## 6. 验证 BLE

### 用 nRF Connect

1. 扫描，应看到 `AuroraLight-XXXX`。
2. 展开服务 `0000BBB0-0000-1000-8000-00805F9B34FB`。
3. 应看到：
   - Control：`0000BBB1-...`，可写
   - Status：`0000BBB2-...`，Notify
   - Info：`0000BBB3-...`，只读
4. 向 Control 写入 `11 01 01 01 14`，灯应点亮。
5. 写入 `11 08 01 01 1B` 应切红色；`11 03 01 01 16` 应切呼吸。

### 用 App

1. 打开幻彩灯控，授予蓝牙权限。
2. 点“连接灯光”，选择 `AuroraLight-XXXX`。
3. 连接成功后测试开关、亮度、颜色、光效和速度。
4. 若 App 报“未找到自定义服务”，检查固件 UUID 是否被改动、是否成功启动 BLE。

## 7. 让灯效更好

- **颜色校准**：不同批次灯珠色偏，可在固件里对 RGB 做系数校正。
- **音乐律动**：当前固件用模拟节拍；要真实随音乐，可接 MAX9814/INMP441，读取包络并映射到亮度。
- **多灯同步**：多个 ESP32 各自作为从机，App 一次只能连一个；需要多灯同步时，可让一个主机 ESP32 通过 ESP-NOW 广播状态给其他从机。
- **断电记忆**：用 `Preferences` 库把状态写入 NVS，上电恢复。
- **安全**：BLE 不配对不加密，仅适合个人氛围灯；不要用于门锁等场景。
